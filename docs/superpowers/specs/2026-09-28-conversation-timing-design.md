# 对话完成时间展示设计

## 目标

一次模型回合完成后，在 TUI 底部状态栏展示该回合耗时，以及距离回合完成经过的相对时间，例如“耗时 1分23秒 · 10分钟前”。

## 边界

- 计时从提交回合开始，到前台运行器收尾完成为止。
- 相对时间使用进程内单调时钟计算，状态栏刷新时动态更新。
- 只修改状态栏，不向滚动转录追加时间元数据。
- 新回合开始时清除上一回合的计时；暂停、失败、取消和部分完成等收尾状态也保留本回合计时。
- 不修改 Sessions schema，因此重启后恢复的历史对话暂不显示这项瞬时计时信息。

## 展示规则

- 小于 1 分钟：`刚刚`
- 小于 1 小时：`N分钟前`
- 小于 1 天：`N小时前`
- 之后：`N天前`
- 耗时使用 `秒`、`分秒`、`小时分` 的紧凑中文格式。

## 验证

- 覆盖新回合清理旧计时。
- 覆盖刚完成、分钟级和小时级相对时间格式。
- 覆盖完成态状态栏包含总耗时与相对完成时间。
