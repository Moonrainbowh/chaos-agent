## 主要变化

- 工具连续调用以实际进展和任务结果收敛，未知执行结果保留为 unknown；模型文字不能替代系统验证回执。
- 分层规则按完整约束加载，规则额度 6,000；用户本次指定工具提示额度 20,000、总提示预算 300,000，最终请求仍受 API、窗口、安全余量及各项预留约束。
- 任务、审批、未决动作与子任务授权绑定到持久状态和明确归属；恢复核对已执行事实，防止重复副作用和跨作用域授权。
- 历史原文、项目记忆及多窗读取有界，来源与旧策略迁移可核对；persistent 手动换窗保留任务和累计预算，笔记作为待核实资料读取。
- 手机审批和任务状态对齐后端事实，配对撤销、断线补取及中文部分交付状态有实际手机与固定故障证据。
- MCP 生命周期及超时清理可追踪；Python 3.10 使用锁定 async-timeout 兼容路径，保留原启动和关闭期限。
- 运行包与开发基准包分开交付；数据升级和回退在隔离副本上演练，保留旧备份与升级后数据，不自动迁移真实用户库。
- CI 纳入全部 30 个套件；Windows 根测试分为 133 个模块，发现和执行身份逐项对账。每模块 600 秒是模块期限，不是全根总期限。
