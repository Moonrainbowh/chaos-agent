# S16 父复核模型变体

用户于 2026-10-10 授权更换父复核模型。此候选仅把 independent、comparison
和它们已有的一次 repair 请求送至实际目录返回的 `global:gpt-6-astra`。
普通主轮与实际子任务仍为 `glm-5.3-flash`，不修改全局配置或生产默认路由。

沿用真实 Host TaskService、原四文件及断言、medium、4096
输出上限、12 rounds / 40 tools / 1000000 tokens、原 child 300000 / 5 / 240s、
timeout60 / retries2 和 900s 进程监督。上下文值沿用原 Host 上限，模型目录只证明
ID 存在，不证明远端容量或语义能力。没有执行被审查函数、测试或候选错误实现。

`adapter.py` 只装配当前主 engine 实例，独立阶段开始前持久冻结模型身份；选择与
事件、prepared request 和共享预算使用同一真实客户端。每轮结束或异常后恢复
GLM。旧未绑定 checkpoint 不冒充此变体。此代码属于开发验收 harness，尚非产品
配置功能，也不能把新结果登记为原 GLM 候选通过。

`run.py prepare/check` 不解析密钥、不调用模型；`execute` 独占一次新尝试。
仅凭退出码、结构校验或 HTTP200 均不能通过语义验收。检查实际 wire、原始响应、
durable review/attempts、sources hashes、事件与按请求结算，再独立检查具体见证
和子报告的每条关键主张。失败或未知结果原样保留，不通过重复抽样制造 PASS。

只运行相关定向测试，每份冻结候选独占一次真实尝试，不运行全量测试。

宿主合成后执行原完整校验，并保存原差量及合成稿。只改变重复输出方式，不增加
