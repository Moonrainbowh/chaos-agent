# 中文输出与空结果收敛设计

## 目标

让 Chaos Agent 面向用户的规划、过程说明、最终结论和错误提示默认使用简体中文，同时保留文件名、路径、代码、命令、API、模型名与专业术语的原文形式。修复模型仅调用工具后任务结束却没有最终结果的问题。

## 范围

- 修改 Windows 与 POSIX 宿主提示，使模型生成的用户可见文本默认使用简体中文。
- 本地化 TUI 的规划标题及相关固定状态文案。
- 在模型产生无正文工具回合时，提供一个禁止工具调用的总结回合。
- 若总结回合仍无正文，依据可信的运行时事实向用户显示明确错误，不再静默结束。
- 为上述行为添加内核与界面回归测试。

## 不在范围

- 翻译用户提供的源文件、文件路径、代码、命令、API 或专业术语。
- 改变工具调用、验证、任务完成或持久化证据的判定规则。
- 改变非 Windows/POSIX 以外的产品文案。

## 方案

### 语言策略

在宿主系统提示中加入统一语言约束：所有面向用户的解释、计划、结果和下一步使用简体中文；不可翻译或翻译后会降低精确性的标识保持原文。规划协议中的阶段名称、动作说明和 `<plan>` 内容因此默认为中文。

TUI 的本地固定文案同步改为简体中文，例如将 `Task plan` 改为“任务计划”。模型正文仍由 Markdown 渲染器原样显示。

### 无正文收敛

模型回合只包含工具调用且没有正文时，保留现有工具执行与证据收集流程。达到工具探索收敛条件后，不直接结束用户任务；引擎发起一个 `summary_only` 模型回合：该回合不向模型提供工具，并要求它根据已持久化的工具结果给出中文总结。

若该总结回合请求工具，运行时拒绝该请求并只重试一次无工具总结；若重试后仍请求工具或没有正文，任务保持受控终止路径，并发布一个包含可信原因的运行时错误事件。TUI 将该事件渲染为可见的失败说明和恢复建议，而非只恢复空闲输入框。

### 验证

- 单元测试验证系统提示包含中文输出约束与术语保留规则。
- 引擎测试验证工具回合后会进入无工具总结回合，且总结文本被持久化并显示。
- 引擎和 TUI 测试验证总结回合仍无正文时显示明确失败状态。
- 运行受影响核心与 Interfaces 测试组；若 TUI 可运行，执行代表性交互并检查渲染结果。
