# 本次实现发现与验证

| 发现 | 处理与证据 |
|---|---|
| API 最大容量、客户端工作窗、压缩阈值、累计任务预算之前混用 | profile 能力与 WindowPolicy 分离；预算不再由 context_window + output 决定 |
| 技能提示在原计数之后追加；旧摘要之后还会二次裁剪历史 | managed wrapper 统计完整前缀，选择原始持久消息，发送前再次检查 |
| JSON 传输转义导致 token 估算系统性偏高 | 改为计数解码后的消息内容与工具结构。224k probe：估算 224186，API input 223923；安全余量仍保留 |
| 摘要成本、缓存、失败请求可被漏算 | 统一请求账本；cached 为 input 子集；API 缺失 usage 保留预留，停止声称精确消耗 |
| 重启/更改配置可能扩大预算或丢失旧消耗 | 继承已存在任务用量；首次预算冻结；新请求与结算持久化 |
| 窗口不能在 tool call 与 tool result 之间断开 | 完整组边界测试；并发 CAS；摘要失败不覆盖历史 |
| 有界历史输出可能无法读取长消息后半部分 | 返回精确 sequence + character offset cursor；测试 20000 字符后的尾部恢复 |
| 实验目录置于 AppData 触发既有 SensitivePathError | 保留失败日志（无 API 调用），将 fixture 改到 F 盘独立实验目录，不降低生产敏感路径策略 |
| 根级内部上下文指针变化破坏旧调用者 | 对 legacy 恢复原内部指针；managed 单独组合；相关旧模式回归已通过 |

## 实验与解释边界

所有实现修正和试跑均先于正式任务冻结。普通 summary 基线获得完整同源历史、相同工具与 handoff 输出额度。固定前史与公开审计样例为合成压力现场，隐藏检查不进入执行工作区。正式结果只适用于这 10 个压缩后代码契约恢复任务。

已知局限：每对只有一次运行；尚未证明多个连续窗口、多文件复杂真实仓库、其他 provider 或多模态上的收益；未配置可信单价时只报 token，不猜测货币成本。模型显示名称和配置容量不构成对供应商实际最大能力的证明。
