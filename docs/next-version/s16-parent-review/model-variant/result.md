## 问题与修复

测试辨别力取决于同一错误行为在指定输入上的真实静态结果，而不是测试名称、
JSON 格式或一句“已经复核”。原 GLM 的具体见证推演和关键主张覆盖此前均存在错误。
更换父复核模型后的首次变体，完整初判的五组见证已正确，但比较阶段仍失败。
其 9362 字符输出中，直到第 8276 字符才开始比较：预算主要花在重写整份初判上。

生产 v4 将比较响应改为显式确认保留条目、完整更新有变化条目、提交全部比较与当前
未知项。每个初判 ID 必须恰好确认或更新；缺失、重复、重叠或未知确认均拒绝。
宿主合成完整报告后仍检查全部引用、覆盖和见证。原差量及合成稿分别持久保存；
已有一次字段修复额度不增加，旧 v1-v3 快照不迁移。独立阶段仍隔离子报告。

这使比较阶段能把输出预算用于复核和纠错。确认 ID 本身仍不是语义正确性的证明。
