## 修改

- 主子任务共用、Windows/POSIX 共用的 system prompt 按实际可观察行为逐条判断契约，不以主观实现意图否定已满足的行为。

- 对明确指定的来源优先直接完整读取；indexed slices 只使用实际观察到的 generation/signatures；stale 时改读同一已授权文件，不据此断言文件被修改。

没有写入本样例的正确答案，没有新增语义关键词门、重试循环、权限、模型替换或预算扩容。
